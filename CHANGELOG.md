# Changelog

## 0.0.1 (2026-08-21)

Initial release:

- Select any text in a DSH conversation and tap **解释** for a streaming
  Markdown explanation bubble.
- Recursive follow-up questions (select text inside an explanation, up to 6
  levels deep).
- Draggable, copyable overlay bubbles (max 8).
- Settings via Settings → General (「框选解释」): `enabled` / `maxDepth` /
  `maxChars`, persisted to `$DSH_HOME/dsh-bubble-explain.settings.json`.
